# Future work

Work deliberately not done, but which may still be built, is recorded here
(`EN-03.7`). That includes a stated limitation and an evidence gap. A defect
is not recorded here; it is an issue.

Each entry is a heading `## FW-<n> — <title>` followed by these `###` headings,
in this order:

- `What is absent`
- `Why it is not built`
- `What would have to be true to build it`
- `Version cost`
- `Affected repositories`

IDs run from `FW-1` without gaps and are never renumbered or reused. A built or
dropped entry becomes a stub, `## FW-<n> — Built` or `## FW-<n> — Dropped`,
and one line saying what replaced it or why. Another repository's entry is
cited as `<repository>:FW-<n>`.
